# User acceptance testing

**Version:** 0.1 · **Prepared:** 9 November 2026 · **Status:** Proposed review draft; no teacher approval or product test execution claimed.

## 1. Purpose and participants

Teacher/client evaluates agreed classroom tasks and release constraints; campus IT evaluates authorized infrastructure behavior. Hour coordinates evidence. Actual reviewers, test venue and dates remain to be named. User acceptance is distinct from a Sprint Review or successful diagram rendering.
