# User manual outline

**Version:** 0.1 · **Prepared:** 9 November 2026 · **Status:** Proposed review draft; no teacher approval or product test execution claimed.

## 1. Intended readers and status

This is a planned guide for teachers, students, application administrators and network operators. Screenshots and exact button labels must be captured from the implemented supported release.

## 2. Teacher guide

Connect to approved network → open trusted local URL → sign in → create class → share URL/QR/code → start class → inspect actual restriction status → select source and grant capture consent → manage participants → pause/resume/stop sharing as needed → End class → inspect closure and restoration outcomes. Explain that Stop sharing leaves the class open and a restriction profile being saved is not evidence of enforcement.

## 3. Student guide

Connect to the instructed network → open URL/QR → enter required code and agreed optional ID → wait for admission if needed → wait for broadcast or start supported playback → adjust own volume/fullscreen. On temporary interruption, follow status guidance; revoked or ended classes cannot be rejoined automatically. Students do not install a native app.

## 4. Administrator guide

Use assigned application or network scope → configure permitted profiles → review scope/rules → apply only when authorized → inspect verified results and limitations → use approved emergency restoration if necessary → retain unresolved recovery record until verified. SYS and NET permissions differ.

## 5. Troubleshooting messages

| Message | User action |
|---|---|
| Invalid or expired code | Ask teacher for current class code |
| Pending approval | Wait; pending status has no viewing access |
| Admitted, waiting | Stay in class until teacher publishes |
| Media unavailable | Check local connection/status; notify teacher if persistent |
| Access revoked or class ended | Stop viewing; follow teacher instruction |
| Enforcement unverified | Authorized operator reviews actual scope; follow agreed D05 rule |
| Restoration pending/failed | Notify authorized operator; do not report prior network policy restored |
| Certificate/name error | Contact operator to repair intended trusted endpoint; do not count bypass as a solution |
